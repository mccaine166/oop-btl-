# Cinema Revenue Analytics

A demo project for cinema revenue analytics with a Java Spring Boot backend and a React frontend. The current implementation uses in-memory data for the non-MongoDB scope, with analytics, recommendations, and dashboard views ready for integration with real data sources later.

## Tech stack

- Backend: Java 17, Spring Boot 3, Maven
- Frontend: React + TypeScript + Vite
- Data layer: in-memory repository implementation for this demo scope

## Project structure

- `src/main/java` - backend application and services
- `src/test/java` - backend tests
- `frontend/src` - React frontend
- `frontend/package.json` - frontend scripts and dependencies

## Run backend

From the project root:

```bash
mvn spring-boot:run
```

The backend listens on:

- http://localhost:8080

## Run frontend

From the `frontend` folder:

```bash
npm install
npm run dev
```

Then open:

- http://localhost:5173

## Default frontend environment

Copy the example environment file if needed:

```bash
cp frontend/.env.example frontend/.env
```

Then set `VITE_API_BASE_URL` if the frontend should call a different backend URL.

## Available data flow

- In-memory seed data is generated by the backend configuration
- Revenue, F&B, inventory, and recommendation services compute analytics from seeded data
- REST endpoints under `/api` are consumed by the React UI

## Validation

Project validation has been run successfully with:

```bash
mvn test
cd frontend && npm test -- --run
cd frontend && npm run build
```

## Notes

This repository is prepared for GitHub sharing, but MongoDB-backed persistence is intentionally excluded from the current scope. A separate database integration task can replace the in-memory repositories once the MongoDB team completes that work.
